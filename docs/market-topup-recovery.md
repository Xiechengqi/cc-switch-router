# DujiaoPay 充值单恢复

Router 只把 DujiaoPay 认证查单结果作为付款证据。收银台地址必须是官网当前文档给出的 `https://www.dujiaopay.com/checkout/{token}`；其他域名、路径及跳转参数均不展示。URL 不可用时保留已返回的网关订单 ID，并继续对账，不再产生一个不受追踪的新订单。正常的 `order.created`、`order.method_selected`、`order.confirming` 回调只用于绑定订单和触发查单，不证明付款，也不再误开人工核对单。

旧版本把 `order.created` 误判为未知事件的订单，仅在网关认证查询确认 `expired`/`canceled`，且没有付款事件、其他争议、充值回执或账本分录时，后台才会在同一数据库事务内关闭旧核对单并释放待处理名额。已付款、身份或金额不符、未知网关状态一律不得自动释放；已付款仍须通过原有严格回执和账本校验。

Owner 可在「设置 → Marketplace → 待核对充值单」逐笔处理未自动恢复的订单。若订单没有保存网关订单 ID，先在 DujiaoPay 商户后台按 Router 商户订单号核对，再填入对应网关订单 ID。先点「向网关核实」进行不写库预检，确认显示可释放后再点「确认终态并释放」。提交会重新认证查单、复核订单身份、金额与版本，并写入操作者及原因代码审计记录；页面预检成功不保证稍后的提交也成功。无法在网关确认终态的订单保持冻结，不能仅通过修改数据库或关闭 case 绕过。

部署前须用真实商户在影子模式验证：建单返回的地址确为上述官方收银台、跳转可用；正常进度回调不冻结订单；取消/过期释放名额；真实链上到账只入账一次；网关超时、错单、退款事件和重复回调均保持资金安全。不得把本地 mock 或只读官网文档当作真实商户验收，也不得为验证而替用户发起真实付款。
