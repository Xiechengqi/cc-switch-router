# Client Market 个人租用记录

## 页面与交互

Client Market 页面在资源表及其分页下方增加「租用历史」，位于 Owner 的「全站租用审计」之前。历史仅包含当前登录用户自己购买／创建的 Client 租用，不是某个 Host 的所有租客记录。

「账号 → 我的租用 → Client 市场」复用同一组件和接口，分为「进行中的租用」和「租用历史」。供应商视角维持原有监控与处理入口，不在本次改动中重构。两个分区独立加载、分页、重试；单个分区失败不阻塞另一个。

每页固定 5 条，支持上一页、下一页和输入页码跳转。主行保留 Client、供应商、租用状态／后续事项，以及当前价格／期限或历史净支出／结束时间。点击行或使用键盘操作展开按钮，才加载详情。详情包含原租用身份、服务时间、清理状态、真实资金、退租结算、付费周期和事件；周期和事件各自以 50 条为一批继续加载。

进行中的租用保留适用的续租设置和服务争议入口，通过「前往市场管理」使用原有 Client 管理和退租流程。历史记录不提供访问已清理 Client、续租或再次释放资源的操作；仍可查看退租处理和联系聊天室。退租对话框放在稳定的工作区中，不随某一条记录的状态归类而卸载。

记录身份来自 `client_market_rental_identities`，不依赖当前 Host 列表。Host 删除、重新出租或 Client 清理后，仍显示原记录的子域名和供应商。续费不会重复生成一次租用主记录。旧记录缺失的信息留空，不从今天的 Host 推测。

## 状态与金额

- 开通中、试用中、付费中、免费、暂停和无法确定已停止的记录归入「进行中的租用」。当前分区中有后续事项的记录优先，其余按下单时间、记录 ID 倒序。
- 服务已停止、立即退租已生效或开通失败归入「租用历史」。清理失败、返还处理中和补偿争议不把已停止的服务放回进行中；历史行单独提示后续事项。
- 生命周期与 Owner 审计共用后端判定，停止时间优先使用退租截止、合同结束和订阅释放时间。旧记录只有停止状态时，使用订阅／任务已持久化的更新时间兜底，不伪造精确的清理完成时间。
- 金额来自原合同的账本、周期和交付记录；先分页，再聚合当前页合同，不把周期与交付等一对多表直接连接相加。
- 净支出 = 实际扣款 − 已完成的余额返还。尚未完成的返还没有到账，暂留补偿包含在剩余预付租金内；补偿不额外加到净支出上。
- 纯试用不因展示历史而扣费。缺失原始财务证据时显示证据不足，而不是零；美元金额按整数账本单位的十进制字符串传输，保留小于一美分的精度。
- 租金返还仅进入平台余额，本功能不增加现金退款、提现或邮件发送。

## API、权限与存储

- `GET /v1/client-market/me/rentals?view=current|history&page=1&focus=...`：当前登录买家的记录，返回 `items`、`view`、`total`、`page`、`pageSize`、`totalPages`、`focusedId` 和 `serverNow`。省略 view 为 current。页码须为 1–4294967295 的整数，超过结果页数时校正到最后一页；空集合为第 1／1 页。
- `focus` 可使用原记录 ID 或 installation ID，只在该买家和指定分区内寻找目标，服务端直接计算目标页，无须遍历历史页。
- `GET /v1/client-market/me/rentals/:id?periodCursor=...&eventCursor=...`：详情，分别分页周期和事件。服务端在读取金额、周期和事件前先证明该记录属于当前用户。不存在或属于其他用户的记录均返回 404。

服务端始终从已验证的登录 session 取得 buyer user ID；不接受 URL、邮箱或前端角色传入的买家身份。SQL 在不可变身份源就限定买家，再联接生命周期、计数和分页。列表总数与当前页使用同一个只读事务，详情与资金也在同一次读取事务内。

个人响应使用字段白名单，不透出 Owner 审计的买家邮箱、Host IP／端口、抽成费率、内部凭证和原始部署日志；只为仍在进行的本人租用返回现有受权限保护的管理投影。详情页不会把另一次租用的周期、事件或管理对象拼接到当前记录。

原 `GET /v1/client-market/hosts/:id/usage-history` 会包含多名租客，现仅允许该 Host 当前供应商和 Router owner 读取；普通租用者使用自己的个人记录。前端也按当前账号隐藏及清除 Host 历史。

所有相关读取（包括失败响应）设置 `Cache-Control: private, no-store`。个人记录不持久化到浏览器存储。退出或切换账号会卸载工作区、取消请求并清除详情和处理弹窗；权限错误会清除已读数据。页面不可见时不后台轮询，展开详情时暂停列表静默轮询，避免打断正在编辑的操作；显式刷新和操作完成仍可刷新。

迁移 105 仅增加 `(buyer_user_id, created_at DESC, id DESC)` 索引，不新建资金表、不重写历史身份或金额、不运行任何资金操作。审计折叠时不读取列表或详情，展开后沿用原有固定高度和每页 5 条的布局；详见 [全站租用审计](client-market-rental-audit.md)。
