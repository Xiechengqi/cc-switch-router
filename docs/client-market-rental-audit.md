# Client Market 全站租用审计

## 使用

Client Market 页面内容底部、Host 表格及其分页之后显示「全站租用审计」，仅 Router owner 可见。卡片处于正常文档流，不悬浮或吸附浏览器视口。支持完整邮箱、Client 子域名／编号前缀、完整 Host IP、租用状态、后续事项和 UTC 下单日期范围查询。默认覆盖全部保留历史，每页固定 5 条，独立于上方市场筛选和分页。

卡片在各响应式断点内高度固定；不足 5 条时保留空白，加载、空结果和错误都使用同一个列表区域，不引起卡片伸缩。主表不再内部纵向滚动，只有上一页、下一页和手动输入页码跳转（Enter 或“跳转”按钮提交）。空结果显示第 1／1 页并禁用跳转，首尾页禁用对应翻页按钮。零、负数、小数、指数和超出范围的页码不提交请求；服务端在筛选结果减少时返回最后有效页。查询、重置筛选和手动刷新回到第一页。

主行仅保留 Client、租用者、租用状态／待跟进事项、实扣租金和下单时间；行高一致，过长名称和邮箱截断，完整内容在详情中查看。窄屏将邮箱合并到 Client 单元格，金额与日期可在详情中查看。默认仅展示搜索和状态筛选，邮箱、后续事项和日期放在“更多筛选”弹窗中，不撑高卡片。点击行或使用查看按钮（支持 Enter／空格）打开详情弹窗；翻页、切换筛选或手动刷新时清除选中详情。

一条记录代表一次已提交租用，包括未成功开通的请求、试用、免费／Provider 自用及已结束租用。报价不算租用，续费不增加租用主记录；各付费周期在详情中独立分页。身份与原租用绑定，不依赖 Host 当前租户或当前供应商。Client 清理、Host 删除后仍可查阅。

详情仅在打开时加载，弹窗自身可以滚动，主列表高度不变。显示身份、服务时间、原约定美元价格与续费策略、真实账本金额、冻结的周期抽成／退租费率和去重后的事件时间线；付费周期与时间线默认折叠，各自仍为每批 50 条的独立游标分页，可继续加载历史。关联退租时，可直接打开已有退租处理弹窗，关闭后仍停留在审计详情。审计本身没有资金操作、删除记录或审批入口，也不新增邮件。

## 状态与金额

- 租用、清理、财务后续事项分开展示。结束租用不代表 Host 已清理或租金已返还。
- 试用阶段由平台合同判定，不能把 subscription 的 active 直接视为付费。
- 实际扣款来自已扣款周期和按量结算批次，冻结不算扣款。服务交付不重复计入用户扣款。
- Provider 服务净收益、平台服务抽成、退租补偿分别列出。使用已持久化的原周期金额和费率，不按当前设置重算历史。
- 剩余预付租金包含争议中的暂留补偿，暂留不是额外扣款；所有金额按整数账本单位传输为字符串，保留小于一美分的金额。
- 租金返还仅进入平台余额，不提供现金退款或提现。收益转入 Provider 余额只反映既有自动入账结果。
- 缺失财务证据显示「历史财务证据不足」，不伪装为零。

## 数据与权限

迁移 99 新增 `client_market_rental_identities`，只保存租用历史身份，不复制计费状态或账本。新订单在原提交事务中冻结 Host IP、端口、地区和买卖双方信息，开通时只允许一次性绑定 installation。身份不可变、不可删除，不与运行资源级联删除。

历史记录从租用与开通任务恢复，原开通事件中的 Provider 身份优先于同步后的邮箱；重试任务不重复生成同一安装实例的租用记录。旧订单下单时尚未分配 Host 的，展示原开通任务／租用记录绑定的 Host ID；无法确认的原 IP／地区仍留空，不能从今天的 Host 推断。迁移在回填前建立开通任务索引，以控制大历史升级和最新清理状态查询的成本；不改余额、租金、补偿、试用或任何账本。

`/v1/auth/session/me` 提供服务端计算的 `canAuditClientMarket`。权限依据 `router_owner_email`，不是普通 `isAdmin`；前端能力仅用于展示，两个审计接口每次都调用 `require_owner_session`。

- `GET /v1/admin/client-market/rental-audit?page=1`：列表，返回 items、total、page、pageSize（固定 5）、totalPages、serverNow。省略 page 默认第一页；page 为 1–4294967295 的整数，超出当前结果的页码校正至末页，非法参数拒绝。列表不再使用 cursor。
- `GET /v1/admin/client-market/rental-audit/:id`：详情；periodCursor、eventCursor 分页各自的周期和事件。

所有响应为 `private, no-store`。不返回密码、SSH 凭证、原始部署日志或完整内部事件 JSON。退出、失去 Owner 能力或切换账号时卸载区域、取消请求和清除内存状态；列表或详情返回 401／403 时也清除当前列表和详情。不把审计数据持久化到 localStorage。

只在初次查看、明确查询／翻页／刷新和相关退租变化时读取；无全站高频轮询。总数与当前页在同一读取事务中查询，按创建时间降序、ID 降序稳定排序，直接使用参数化 LIMIT／OFFSET 到达目标页，不遍历游标或前端加载全量历史。跨请求读取实时数据，新增记录或状态筛选变化可以改变页位，不提供跨页永久快照。深页访问仍有 OFFSET 成本。先分页，再按当前页合同批量聚合资金，避免 N+1 和多表一对多连接造成金额倍增。

## 验证

Rust 覆盖 125 条记录／25 页的同时间戳全量遍历、直接跳页、空页与末页不足 5 条、越界及筛选结果收缩、历史身份保留、查询参数、真实合同试用与月租、立即退租返还／补偿／争议暂留、成熟收益入余额、超过 50 个周期和事件的独立分页，以及索引查询计划。前端单测覆盖分页响应和页码输入校验、金额精度、日期边界和翻译；首页导航决策单测覆盖带／不带尾斜杠的客户端路径、所有默认入口、匿名及失败降级、首次引导和任务深链。

本次实施的验证范围为后端测试、前端逻辑单测、类型检查和生产构建，不截图、不执行 UI 自动化。既有 CI 浏览器测试的数据桩与断言同步为新分页及弹窗契约，但不在本次本地验证中运行。
